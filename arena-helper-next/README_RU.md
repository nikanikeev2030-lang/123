# Arena Helper RU 1.1.4

Восстановлен из предоставленного APK 1.1.3: русский OCR, выбор героя, группы, верхняя панель и боковые кнопки, счётчик и автоматический учёт выбора сохранены. При ошибке автоматического учёта нажмите выбранную карту в панели.

Изменения:
- Дополнительный проход для мелких длинных названий увеличивает исходное изображение ДО бинаризации, использует несколько изгибов и белую рамку. Ослабленное сопоставление допускается только для длинных строк, при отрыве от второго кандидата и подтверждении несколькими проходами. Короткие названия не угадываются по этому правилу.
- При 0–13 уже выбранных картах следующая карта (1–14) оценивается только по силе. При 14–29 выбранных картах (15–30) итог = округление(0.7 × сила + 0.3 × кривая). Четыре стартовые карты входят в счётчик. Если стоимости выбранных карт неизвестны, кривая не выдумывается: применяется сила.
- Обновление загружает текущие рейтинги HearthArena, русские метаданные HearthstoneJSON, группы и статистику обычной Арены HSReplay. Режим источника проверяется. Ошибка основной базы оставляет прежний файл; запись атомарная. Недоступность групп или статистики не мешает обновить карты, но эти разделы остаются пустыми до успешного обновления; приложение сообщает об этом. Для применения обновления перезапустите захват.

Пул здесь — каталог оценённых карт и карт из групп источников, а не официальный список доступности каждого предложения Blizzard. Автоматическое обновление по расписанию не выполняется: кнопка «Обновить базы».

Сборка: JDK17, Gradle8.13, SDK35. GitHub Actions проверяет JVM-тесты, Lint, подпись и ARM64/16КБ, затем нативный OCR, загрузку данных и запуск в Android-эмуляторе. Пользовательские скриншоты не публикуются. На физическом POCO F7 / HyperOS3 не проверено.

Для установки при конфликте подписи удалите предыдущий APK; настройки и учёт колоды будут сброшены. Сборка подписана debug-ключом.

Источники: https://www.heartharena.com/en/tierlist ; https://api.hearthstonejson.com/v1/latest/ ; https://hsreplay.net/api/v1/arena/classes_stats/?game_type=BGT_ARENA ; https://hsreplay.net/api/v1/arena/card_packages/free/?game_type=BGT_ARENA . Оценка силы — шкала HearthArena, не процент побед. Формула манакривой — эвристика.

## 1.1.5
Первые 14 карт: сила. С 15-й: 70% сила + 30% манакривая. Если часть выбранных карт пропущена, кривая рассчитывается приблизительно: известные карты + сглаженная оценка распределения неизвестных. Пометка ≈ и число известных карт показывают полноту данных.
Герои распознаются отдельно в трёх колонках, включая многострочные названия. Пропущенный класс не сдвигает соседей; показывается даже один распознанный класс. При сбое загрузки рейтингов сохраняются прежние значения с пометкой «кэш».
