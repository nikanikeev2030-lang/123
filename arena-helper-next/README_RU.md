# Помощник на Арене Hearthstone 1.4.0

Лицензия на одно устройство, серверное распознавание карт и героев без OCR.
Полные базы и их обновление перенесены на сервер. APK получает результаты текущего предложения,
а не копию каталога. Для распознавания требуется интернет.

[Развёртывание сервера, выдача лицензий и сборка APK](license-server/README_RU.md).

Android 11+, разрешения на оверлей и MediaProjection. Первые 14 карт — сила,
с 15-й — 70% сила + 30% манакривая. Без настроенного LICENSE_URL активация закрыта.
