# Arena Helper RU 1.2.0

Разрешите захват экрана и показ поверх игры. Панель распознаёт три предложения Арены по рисункам, сравнивая цветовые отпечатки с эталонами HearthstoneJSON. Русские названия и рейтинги берутся из каталога. Если расположение отличается, кнопка «Зоны» позволяет выделить центральную часть каждой иллюстрации. Первые 14 карт оцениваются по силе, остальные по силе (70%) и манакривой (30%). Кэшированные винрейты классов отмечены в панели.

Счётчик ведётся по смене предложений и выбору карты. Если стоимость выбранной карты неизвестна, манакривая приблизительная. Коснитесь счётчика для исправления количества карт или ручного выбора класса. «Обновить базы» загружает рейтинги, группы и отпечатки новых карт. После обновления перезапустите захват. Для распознавания подключение к сети не требуется.
