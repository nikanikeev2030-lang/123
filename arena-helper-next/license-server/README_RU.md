# Сервер лицензий Arena Helper RU 1.3.0

Статус: реализация готова для развёртывания, публичный сервер ещё не подключён.
Без LICENSE_URL приложение закрывает доступ. Тестовый APK не предназначен для продажи.

## Как работает

Покупатель вводит код AH-… . Приложение создаёт EC P-256 ключ в Android Keystore.
На сервер отправляются код лицензии, открытый ключ, время, одноразовый nonce и подпись.
Закрытый ключ телефона не отправляется. Сервер атомарно закрепляет лицензию за первым ключом.
Копия APK или кода на втором телефоне не активируется. Приватные ключи продавца в APK не нужны.

Сервер выдаёт разрешение на 15 минут; приложение обновляет его каждые 5 минут.
После перезапуска процесса требуется повторная активация сохранённым кодом.
При потере сети текущая сессия работает до истечения разрешения; затем останавливается
(проверка раз в минуту). Отзыв действует при следующей успешной проверке, максимум
через 15 минут плюс интервал проверки. Покупателю нужно сообщить об этом до продажи.
Дата телефона должна быть верной, допуск 5 минут. Скриншоты не передаются серверу.

## Развёртывание на VPS

Нужны Docker Compose, домен с DNS A/AAAA на сервер, открытые порты 80 и 443.
В каталоге license-server создайте .env: LICENSE_DOMAIN=license.ВАШ-ДОМЕН
Запустите `docker compose up -d --build`. Caddy получает HTTPS-сертификат автоматически.
Проверьте https://license.ВАШ-ДОМЕН/health — ответ {"ok":true}.
База находится в постоянном Docker volume licenses. Регулярно сохраняйте её резервную копию.
Бэкапы содержат привязки и хеши лицензий, храните их приватно. Не публикуйте базу в GitHub.
Только reverse proxy доступен извне: порт приложения 8000 не публикуется.
Административного HTTP API нет. Администрирование — через SSH/консоль хостинга.

## Выдать, отозвать, перенести

Выдать: `docker compose exec api python server.py issue --label ORDER-123`
Код выводится один раз. Передайте его покупателю приватно, не публикуйте в Issues/Actions.
Отозвать: `docker compose exec api python server.py revoke` — код вводится скрыто.
Перенести: сначала revoke, выждите 16 минут, затем `docker compose exec api python server.py reset`.
После reset первый телефон с кодом получит привязку. Для безопасного переноса выдайте новый
код новому устройству после отзыва старого: иначе человек со старым кодом может активироваться первым.
Удаление приложения/сброс телефона удаляет ключ Keystore: необходим перенос продавцом.
Обычное обновление APK с прежней подписью сохраняет ключ и привязку.

## Коммерческая сборка

Настройте Gradle -PLICENSE_URL=https://license.ВАШ-ДОМЕН/v1/activate .
Без этого параметра assembleRelease/bundleRelease завершается ошибкой.
Постоянный ключ подписи приложения обязателен: создайте release keystore, храните резервную копию
в безопасном месте. Не используйте debug-подписи GitHub Actions для продажи.
Переменные среды: ARENA_KEYSTORE, ARENA_STORE_PASSWORD, ARENA_KEY_ALIAS, ARENA_KEY_PASSWORD.
Запуск: gradle -PLICENSE_URL=https://license.ВАШ-ДОМЕН/v1/activate assembleRelease.
Пароли и keystore запрещено добавлять в репозиторий. Смена ключа приложения потребует переустановки
и новой привязки всех покупателей.

## Проверки и ограничения

`python -m unittest -v` проверяет привязку, гонку двух активаций, повтор запроса, поддельную
подпись, отзыв, перенос, часы, сохранение базы и ограничения HTTP.
Android instrumentation проверяет Keystore, транспорт активации, отказ и запуск захвата после активации.
Production не разрешает HTTP; debug допускает только 127.0.0.1 для тестов.

Защита рассчитана на штатный APK, а не на взломанный клиент/root. Аппаратная аттестация и
Play Integrity пока не включены; сервер не доказывает, что присланный ключ создан штатным APK.
Вычисление рейтингов и каталог пока находятся в APK. Умышленно модифицированный клиент может
обойти локальную проверку. Старые свободные APK 1.2.x этой лицензией не блокируются.
Для более сильной защиты следующий этап — выдача закрытых данных сервером и аттестация клиента.
Нет платежной интеграции: код выдаётся продавцом после оплаты.
