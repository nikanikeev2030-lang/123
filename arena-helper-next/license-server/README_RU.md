# Помощник на Арене Hearthstone — серверная версия 1.4.0

В APK нет каталога карт, рейтингов, портретов героев и эталонов изображений.
Телефон не скачивает базы ни с публичных сайтов, ни с нашего сервера. Он отправляет
10×8 RGB-отпечатки фиксированных областей трёх предложений. Полный скриншот не передаётся.
Сервер возвращает только распознанные карты текущего предложения, их оценки и группы,
а также небольшую таблицу статистики 11 классов. Манакривая вычисляется на телефоне по текущей колоде.

## Доступ

Код AH-… привязывается к открытому EC P-256 ключу телефона. Закрытый ключ создаётся в Android Keystore.
Каждый запрос распознавания требует подписи устройства, действующей лицензии, времени и одноразового nonce.
Подпись включает действие и SHA-256 содержимого запроса. Нельзя заменить запрос или повторить его.
Лимит: 120 запросов в минуту на ключ устройства. Одновременно принимаются ровно три слота.
Нет маршрута выгрузки всей базы или публичного административного API.

Активация обновляется каждые 5 минут; локальное разрешение запуска живёт до 15 минут.
Но новые результаты распознавания всегда требуют связи: офлайн-работы в 1.4.0 нет.
Отзыв лицензии блокирует следующий запрос к данным сразу, даже если локальное разрешение ещё живо.
При ошибке сети панель убирает прежние оценки; отсутствие ответа не считается выбором карты.
Удаление приложения удаляет ключ и требует переноса продавцом. Обновление с прежней подписью сохраняет ключ.

## Запуск

Нужны VPS с Docker Compose, домен на IP сервера и порты 80/443.
Создайте `.env` рядом с compose.yaml: `LICENSE_DOMAIN=license.ВАШ-ДОМЕН`.
Запустите `docker compose up -d --build`.
`https://license.ВАШ-ДОМЕН/health` должен вернуть `{"ok":true}`.
Порт API 8000 не публикуется. HTTPS обслуживает Caddy, сертификат обновляется автоматически.
При первом старте сервер собирает приватный снимок `/data/database.json.gz` из начальных эталонов seed.
Сервис updater обновляет данные при старте и затем каждые 6 часов.

## Обновление базы только на сервере

Ручной запуск: `docker compose exec api python update_database.py`.
Логи автоматического обновления: `docker compose logs --tail=100 updater`.
Источники: HearthArena (рейтинги), HearthstoneJSON (метаданные и обычные изображения),
HSReplay (обычная Арена, группы и винрейты классов). Проверяются полнота, цены маны, рейтинги,
формат отпечатков и режим Арены. Новый файл подменяет старый атомарно только после проверки.
При ошибке основного источника старая база сохраняется. Недоступная статистика героев сохраняется с отметкой «кэш».
Новые обычные карты получают отпечатки автоматически. Специальные иллюстрации и новые портреты,
которых нет среди 205 дополнительных эталонов и 705 портретов seed, требуют добавления эталонов на сервер.
Обновлённая база не публикуется в GitHub и не включается в APK.

Кнопка телефона «Проверить базу сервера» читает только дату и количество карт, а не запускает обновление источников.
При первом запуске удаляются старые файлы catalog-update.bin и их резервные копии от автономной версии.

## Выдача лицензий

Выдать: `docker compose exec api python server.py issue --label ORDER-123`.
Код выводится один раз; передайте его покупателю приватно.
Отозвать: `docker compose exec api python server.py revoke` — код вводится скрыто.
Перенести: отозвать, выждать 16 минут, затем `docker compose exec api python server.py reset`.
Безопаснее после отзыва выдать новый код: иначе человек со старым кодом сможет первым перепривязать его после reset.
Платежи пока не подключены, продавец выдаёт код после оплаты вручную.

## APK

Собрать с `-PLICENSE_URL=https://license.ВАШ-ДОМЕН/v1/activate`.
Для GitHub Actions URL можно задать repository variable `LICENSE_URL` (это публичный адрес, не секрет).
Постоянная release-подпись обязательна: ARENA_KEYSTORE, ARENA_STORE_PASSWORD,
ARENA_KEY_ALIAS, ARENA_KEY_PASSWORD. Храните ключ и резервную копию отдельно от репозитория.
Команда: `gradle -PLICENSE_URL=https://license.ВАШ-ДОМЕН/v1/activate assembleRelease`.
Без сервера и постоянной подписи коммерческая сборка запрещена. Debug-APK CI без URL не активируется.
После смены сервера или сертификата подписи приложения может потребоваться новая сборка/перепривязка.

## Проверки и пределы защиты

`python -m unittest -v`: лицензии, два устройства, подписи запросов, повтор, отзыв, лимиты,
серверное распознавание специальных версий, герои, сохранение прежней базы при ошибке обновления.
Android CI поднимает отдельный временный Python-сервер и проверяет реальные запросы от Android Keystore,
распознавание трёх карт, разрешение MediaProjection и оверлей на Android 11/15.
Проверка APK запрещает assets баз и URL публичных загрузчиков в DEX.

Это не абсолютная защита: лицензированный покупатель видит результаты и может их сохранять;
не внедрены аппаратная аттестация и Play Integrity. Прокси через разрешённый телефон и
модифицированные клиенты требуют дополнительного контроля. Старые автономные APK 1.2.x
и уже опубликованные базы эта архитектура не отзывает и не делает секретными.
Регулярно резервируйте Docker volume licenses (привязки и база), не публикуйте его.
Права на коммерческое использование сторонних данных должны быть урегулированы отдельно.
