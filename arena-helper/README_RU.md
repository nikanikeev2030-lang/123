# Arena Helper RU 1.0.5

Неофициальный помощник для выбора трёх карт Арены Hearthstone на русском языке.
Kotlin, MediaProjection, Tesseract4Android 4.9.0 с rus.traineddata, TYPE_APPLICATION_OVERLAY.
Android 11+, ARM64, targetSdk 35. На физическом POCO F7 / HyperOS 3 не проверен.

## Установка

Скачайте artifact Arena-Helper-RU-APK из успешного запуска GitHub Actions, распакуйте и установите Arena-Helper-RU.apk.
APK подписан debug-ключом. При несовпадении подписи с предыдущей локальной сборкой удалите старую версию перед установкой.
Для долговременных обновлений требуется постоянный приватный release-ключ; текущий workflow не содержит секретов.

1. Выберите класс героя в приложении.
2. Разрешите показ поверх приложений, затем запустите помощник и подтвердите захват экрана.
3. Откройте экран выбора трёх карт Арены горизонтально.
4. Стартовые рамки настроены для стандартного поля. Если названия не распознаны, нажмите «Зоны», выберите 1/2/3 и обведите только названия карт. Нажмите «Готово».
5. Два последовательных совпадения названий и наличие всех трёх оценок включают зелёную подсветку ★ ЛУЧШИЙ. Равные максимумы выделяются вместе.
6. Используйте «Пауза» вне драфта: приложение не определяет экран драфта автоматически. «×» или действие уведомления прекращает захват.

После смены класса перезапустите помощник. При изменении масштаба игры повторите калибровку.
Если HyperOS закрывает приложение, проверьте разрешения всплывающих окон и фоновой работы.
Точность на золотых картах, анимированных названиях и шрифтах игры требует проверки на устройстве.

## Данные

В APK включён статический снимок https://www.heartharena.com/tierlist; дата видна в приложении.
Оценки зависят от выбранного класса. Это шкала источника, не процент побед; синергия колоды не вычисляется.
«Нет оценки» означает отсутствие данных, а не нулевую силу. Названия: https://hearthstonejson.com.
Игра, карты и материалы принадлежат Blizzard; оценки — HearthArena. Приложение не связано с этими компаниями.
В коде нет рейтингов, выдуманных по характеристикам карты. Для нового сезона требуется новый снимок.
Кадры не сохраняются и не отправляются. INTERNET permission отсутствует.

## Сборка

JDK 17, Gradle 8.13, Android SDK 35 / Build Tools 35.0.0.

```sh
python3 tools/fetch_ocr.py
gradle testDebugUnitTest lintDebug assembleDebug
python3 tools/verify_apk.py app/build/outputs/apk/debug/app-debug.apk
```

Модель OCR скачивается с официального tessdata_fast 4.1.0 и проверяется по SHA-256.
Для обновления каталога загрузите `cards.collectible.json` enUS/ruRU с https://api.hearthstonejson.com/v1/latest/ в tools/en.json и tools/ru.json, а HTML таблицы HearthArena — в tools/tierlist.html. Выполните `python3 tools/build_catalog.py`.

## GitHub Actions

Workflow в корне репозитория: `.github/workflows/arena-helper-ru.yml`.
Push в ветку arena-helper-ru запускает сборку в папке arena-helper. Artifact содержит APK, SHA-256 и README.
Отдельный artifact содержит отчёты тестов и Lint. Восстановлены изменения из предоставленного APK 1.0.4. Исправлены циклы сегментации текста и бинаризации. Добавлены выпрямление названий и автоматические рамки по игровому полю 16:9.

Кнопки калибровки: 1/2/3 выбирают рамку, «Сброс» возвращает шаблон, «Отмена» не сохраняет изменения. В 1.0.5 старые рамки мигрируют на новый шаблон.

Workflow проверяет нативный OCR в Android-эмуляторе на искусственно созданных изображениях с русскими названиями карт. Скриншоты пользователя в репозиторий не включены. Эти проверки не заменяют испытание MediaProjection и ограничений HyperOS на реальном POCO.

На экране выбора легендарных групп показана базовая оценка видимой карты, а не сила всей группы или синергия колоды.

Tesseract4Android и tessdata_fast: Apache-2.0; тексты лицензий включены в assets/licenses.
